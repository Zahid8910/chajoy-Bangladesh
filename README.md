# ChaJoy-Bangladesh

ChaJoy-Bangladesh is a web development project designed to provide a simple and engaging digital experience for discovering and exploring Bangladesh.

## Overview

ChaJoy-Bangladesh was developed as a web technology project with a focus on creating an accessible, visually engaging, and user-friendly web experience.

The project demonstrates the use of front-end web technologies to structure content, design interactive interfaces, and create a responsive website.

## Features

- Responsive web interface
- Interactive navigation
- Structured content presentation
- Visual exploration of Bangladesh
- User-friendly interface
- Responsive design for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
